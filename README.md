# -Text-Analysis-using-Python
## AI & ML Internship

### Project Overview
This project analyzes a given text using Python and calculates the number of words, characters, vowels, and repeated words.

### Objective
To practice basic text processing techniques useful in Natural Language Processing (NLP).

### Tools Used
- Python
- Jupyter Notebook
- Google Colab

### Features
- Count total words
- Count total characters
- Count characters without spaces
- Count total vowels
- Identify repeated words and their frequencies

### Python Concepts Used
- `split()`
- `len()`
- `lower()`
- `replace()`
- `Counter()`
- Dictionaries
- String manipulation

### Sample Input
```text
Artificial intelligence is changing the world.
Artificial intelligence helps people solve problems.
Python is useful for artificial intelligence.
```

### How to Run the Project
1. Open Google Colab or Jupyter Notebook.
2. Create a notebook named `Text_Analysis.ipynb`.
3. Copy the Python code into a cell.
4. Run the code.
5. Check the text analysis report.
6. Save or download the notebook.

### Expected Results
The program displays:
- Total words
- Total characters
- Characters without spaces
- Total vowels
- Repeated words
